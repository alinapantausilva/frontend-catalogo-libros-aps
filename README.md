# Frontend Proyecto Catálogo de Libros 

Proyecto final del bootcamp de Neoland Web Development

## Descripción 

Aplicación web para gestionar un catálogo de libros

## Tecnologías

- React
- Vite
- Css
- Javascript

## Cómo clonar el repositorio

```shell
git clone <url_repo>
git switch dev
```

## Cómo ejecutar el proyecto

``` shell
npm install
npm run dev

```
